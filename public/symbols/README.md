# Symbol drawing assets

Place reviewed standalone SVGs here. Reference them using `svgPath: 'symbols/file-name.svg'` in `src/symbols/catalogue.ts`. Vite's BASE_URL is added by the component for GitHub Pages hosting.

The catalogue contains generic English description slots. Add or adjust entries to match the supplied drawings; do not force a different device variant into an existing slot. Until a path is supplied, a clearly labelled placeholder is shown. The page uses SVG files as images, not injected HTML.
